ستائر أركان الطليعة - تطبيق المقاسات

المزايا:
- ملف واحد لكل زبون مع عدة غرف وشبابيك.
- حفظ تلقائي للمسودة على الجهاز عند إدخال البيانات.
- حفظ الملفات والتعديلات والحذف محليًا عند انقطاع الإنترنت.
- مزامنة تلقائية مع Firebase عند عودة الاتصال.
- حفظ نسخة محلية من قائمة الزبائن لتظهر عند فتح التطبيق دون إنترنت.

مهم قبل الاستخدام دون إنترنت:
1) افتح التطبيق أول مرة مع وجود الإنترنت حتى يتم تحميل الملفات وتسجيل الدخول.
2) اترك الصفحة تفتح بالكامل مرة واحدة حتى يتم تخزين ملفات التطبيق.
3) بعد ذلك يمكن إدخال المقاسات دون إنترنت، وستظهر علامة انتظار المزامنة.
4) عند عودة الإنترنت افتح التطبيق واتركه متصلًا حتى تكتمل المزامنة.

تنبيه: البيانات المحلية موجودة على نفس الجهاز/المتصفح. لا تمسح بيانات التطبيق أو ذاكرة التخزين المؤقت قبل اكتمال المزامنة. تسجيل الدخول المجهول الأولي إلى Firebase يحتاج إنترنت.

قاعدة البيانات المستخدمة: arkan-curtains (Realtime Database).
