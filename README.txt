ستائر أركان الطليعة — نسخة دخول تلقائي وربط Firebase

التعديل في هذه النسخة:
- يحاول التطبيق تسجيل الدخول تلقائيًا باستخدام Firebase Anonymous Authentication.
- يقرأ ويحفظ ويعدّل ويحذف بيانات الزبائن من Realtime Database تحت المسار customers.
- لا يحتاج العامل إلى إدخال بريد أو كلمة مرور.

قبل الاستخدام:
1) في Firebase Console > Authentication > طريقة تسجيل الدخول، فعّل «مجهول / Anonymous».
2) في Realtime Database > Rules انشر القواعد الموجودة في FIREBASE_RULES.json.
3) انشر index.html وapp.js على استضافة HTTPS تدعم JavaScript modules، مثل GitHub Pages.
4) افتح رابط الموقع على الجوال وجرّب سجلًا تجريبيًا، ثم افتح الرابط على جوال آخر.

تنبيه أمني مهم:
هذه النسخة تستخدم تسجيل الدخول المجهول؛ ومع القواعد التي تسمح لكل مستخدم مصادق بالقراءة والكتابة، يستطيع أي شخص يصل إلى التطبيق ويُسجّل دخولًا مجهولًا الوصول إلى بيانات الزبائن وتعديلها أو حذفها. هذا ليس مناسبًا لبيانات حقيقية عامة. استخدمها للاختبار فقط إلى أن تُضبط حماية أقوى، أو استخدم حسابات للعمال.

لم يتم نشر الموقع على الإنترنت أو اختبار اتصال حي بحساب Firebase من هذه الحزمة. ملف ZIP ليس APK.
